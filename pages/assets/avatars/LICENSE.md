# Avatar images

The SVG files in this folder are sample cardholder and team member photos for the prototype.
Each file is named after the person's ID (`ch_…` for cardholders, `usr_…` for team members) and was generated
deterministically from the person's name with DiceBear 9.4.2, style "Notionists". Metadata was stripped and
coordinates rounded to keep each file around 10 KB.
